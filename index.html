bot de Discord.

Aprendé cómo se organiza un bot con Python y la biblioteca discord.py. Este ejemplo es educativo: no contiene tokens ni credenciales.

  1. 01
    Prepará el entorno

    Instalá Python y discord.py en una computadora o entorno compatible.

  2. 02
    Creá tu aplicación

    Usá el portal de desarrolladores de Discord y configurá los permisos necesarios.

  3. 03
    Probá un comando slash

    Empezá con un comando simple y después agregá funciones de forma gradual.

PORTAL DE DISCORD ↗
bot.py
import discord
from discord import app_commands
from discord.ext import commands

intents = discord.Intents.default()
bot = commands.Bot(command_prefix="!", intents=intents)

@bot.event
async def on_ready():
    print(f"Conectado como {bot.user}")
    await bot.tree.sync()

@bot.tree.command(name="hola", description="Saluda al servidor")
async def hola(interaction: discord.Interaction):
    await interaction.response.send_message(
        f"¡Hola, {interaction.user.mention}!"
    )

# Configurá DISCORD_TOKEN como variable de entorno.
# No publiques ni compartas tu token.
