# 💻 CODE LAB — Academia de programación

> **Aprendé. Practicá. Construí.**  
> Una academia gratuita para quienes quieren empezar a programar desde cero, con explicaciones en español, ejemplos y recursos para seguir aprendiendo.

---

## 🚀 ¿Qué es CODE LAB?

CODE LAB es un proyecto educativo pensado para personas que quieren descubrir el mundo de la programación sin necesidad de tener experiencia previa. La idea es aprender los fundamentos, practicar con ejemplos pequeños y, poco a poco, construir proyectos propios.

En esta academia vas a encontrar cuatro rutas iniciales:

- **Python:** lógica, automatización, scripts y bots.
- **JavaScript:** páginas web interactivas y aplicaciones.
- **HTML:** estructura y contenido de páginas web.
- **Java:** fundamentos de programación y aplicaciones.

También hay una introducción a la creación de **bots de Discord con Python**.

## 🐍 Python

Python es un lenguaje de programación conocido por su sintaxis legible. Es una buena opción para empezar porque permite concentrarse en la lógica sin tener que escribir demasiadas instrucciones complejas.

### ¿Para qué se usa?

- Automatizar tareas repetitivas.
- Procesar archivos y datos.
- Crear pequeños programas y herramientas.
- Desarrollar bots de Discord usando bibliotecas como `discord.py`.
- Aprender conceptos que después se aplican a otros lenguajes.

### ¿Qué conviene aprender primero?

1. Variables y tipos de datos.
2. Texto, números y operadores.
3. Condiciones (`if` y `else`).
4. Bucles (`for` y `while`).
5. Funciones.
6. Listas, diccionarios y manejo de errores.
7. Archivos, módulos y bibliotecas.

**Proyecto para principiantes:** crear una calculadora sencilla o un programa que muestre un menú de opciones.

## 🌐 JavaScript

JavaScript permite agregar comportamiento e interactividad a las páginas web. Puede responder a clics, validar formularios, modificar contenido y comunicarse con servicios web. También se utiliza fuera del navegador, por ejemplo con Node.js.

### ¿Para qué se usa?

- Crear menús y botones interactivos.
- Validar formularios.
- Actualizar contenido sin recargar toda la página.
- Construir aplicaciones web.
- Desarrollar herramientas y servidores con Node.js.

### ¿Qué conviene aprender primero?

1. Variables (`let` y `const`).
2. Tipos de datos y operadores.
3. Condiciones y bucles.
4. Funciones.
5. Arrays y objetos.
6. El DOM y los eventos del navegador.
7. Promesas y `async/await`.

**Proyecto para principiantes:** crear una lista de tareas con botones para agregar y quitar elementos.

## 🧱 HTML

HTML significa *HyperText Markup Language*. No es un lenguaje de programación tradicional: es un **lenguaje de marcado** que define la estructura y el significado del contenido de una página web.

### ¿Para qué se usa?

- Organizar títulos, párrafos e imágenes.
- Crear enlaces y listas.
- Construir formularios.
- Dar estructura a una página para que los navegadores la interpreten.
- Trabajar junto con CSS y JavaScript para crear sitios completos.

### ¿Qué conviene aprender primero?

1. Estructura básica de un documento HTML.
2. Títulos y párrafos.
3. Enlaces e imágenes.
4. Listas y tablas.
5. Formularios y botones.
6. Etiquetas semánticas como `header`, `main`, `section` y `footer`.
7. Accesibilidad básica.

**Importante:** HTML define la estructura; **CSS** se ocupa principalmente del diseño visual y **JavaScript** de la interacción.

**Proyecto para principiantes:** crear una página personal con una presentación, tus intereses y enlaces útiles.

## ☕ Java

Java es un lenguaje de programación de propósito general, muy utilizado en sistemas empresariales, servicios de backend y distintas clases de aplicaciones. Tiene tipos de datos explícitos y trabaja con clases y objetos.

### ¿Para qué se usa?

- Crear aplicaciones y servicios de backend.
- Desarrollar sistemas empresariales.
- Aprender programación orientada a objetos.
- Trabajar en proyectos que necesitan una estructura clara y mantenible.

### ¿Qué conviene aprender primero?

1. Variables y tipos de datos.
2. Operadores y conversiones.
3. Condiciones y bucles.
4. Métodos.
5. Clases y objetos.
6. Listas y otras colecciones.
7. Excepciones y lectura de archivos.

**Proyecto para principiantes:** desarrollar una aplicación de consola que permita registrar tareas o administrar una lista de contactos.

## 🤖 Introducción a los bots de Discord

Un bot de Discord es una aplicación que se conecta a Discord y puede responder a comandos, ayudar con la moderación, publicar mensajes o automatizar tareas de una comunidad.

Para empezar con Python, una ruta posible es:

1. Aprender variables, condiciones, funciones y módulos.
2. Conocer los conceptos básicos de Python y `discord.py`.
3. Crear una aplicación en el [Portal de desarrolladores de Discord](https://discord.com/developers/applications).
4. Probar un comando slash, por ejemplo `/hola`.
5. Añadir funciones pequeñas, probarlas y revisar los errores.
6. Aprender permisos, registros y manejo seguro de la configuración.

### Seguridad del bot

- **Nunca publiques el token del bot** en GitHub, capturas o mensajes.
- Guardá los secretos como variables de entorno, por ejemplo `DISCORD_TOKEN`.
- Activá solo los permisos e intents que realmente necesite el bot.
- Probá las funciones en un servidor de prueba antes de usarlas en una comunidad real.
- No otorgues permisos de administrador si no son necesarios.

Documentación: [discord.py](https://discordpy.readthedocs.io/en/stable/) y [Portal de desarrolladores de Discord](https://discord.com/developers/applications).

## 🧭 ¿En qué orden conviene aprender?

Si recién empezás, podés seguir esta ruta:

1. **HTML** para comprender cómo se estructura una página web.
2. **CSS** como complemento para aprender diseño y presentación.
3. **JavaScript** para hacer que la página responda a las acciones de las personas.
4. **Python** para practicar lógica, automatización y bots.
5. **Java** cuando estés listo para profundizar en clases, objetos y aplicaciones más estructuradas.

No es obligatorio seguir ese orden. Si tu objetivo principal es crear bots de Discord, podés empezar directamente por Python.

## 💡 Consejos para aprender mejor

- **Practicá un poco todos los días.** La constancia ayuda más que intentar aprender todo de golpe.
- **Escribí el código vos mismo.** Copiar ejemplos sirve para comenzar, pero modificarlos te ayuda a entenderlos.
- **Leé los errores con calma.** Revisá el nombre de las variables, los paréntesis, la indentación y las rutas de archivos.
- **Hacé proyectos pequeños.** Terminá una calculadora o una página sencilla antes de empezar algo enorme.
- **Buscá documentación confiable.** Los tutoriales ayudan, pero las referencias oficiales sirven para verificar cómo funciona cada herramienta.
- **Usá Git y GitHub.** Guardá cambios y aprendé a volver a una versión anterior cuando algo deje de funcionar.
- **Pedí explicaciones, no solo soluciones.** Intentá entender qué hace cada línea y por qué está ahí.
- **Cuidá tus datos.** No subas contraseñas, tokens, claves de API ni información privada a repositorios públicos.
